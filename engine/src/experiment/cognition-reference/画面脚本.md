# 认知行动 · 参考样片实验

仅接入实验入口，不修改正式 V1、正式文章源稿、音频、字幕和成片。

选段为原配音 01:35.300～02:03.933，共 28.633 秒（30fps，859 帧）。从“你在那个瞬间，清晰地认知到了”到“于是，你又拿起了手机”。台词与切屏直接复用现有版本，原样摘录见 `原稿摘录.txt`。`excerpt.json` 保存逐字时刻、语义节拍、原文件摘要；实验配音是原音频的连续截取，无重新配音、变速或拼词。上一句与本句的对齐边界相接，直接从本句开口位置切入，避免保留上一句“都是”的尾音。

## 单幅图持续演进

全段保留“学习”和“刷抖音”两个对象，以及底部“行动”的选择轨道。框的相对大小仅表达当下认知到的价值高低，不是数值、概率或收益测量；图内标签都取自本段意思。变化由原逐字时刻触发。

| 台词落点 | 已有结构 | 变化 | 作用与参考 |
|---|---|---|---|
| 你在那个瞬间／清晰 | 第一帧已显示两种选项和行动点 | 学习框凝实，比较符号展开 | 先建立关系；沿用样片低信息密度与细线 |
| 学习的价值高于刷抖音 | 两个选项 | 学习框更大，比较符号为 >，行动点停在学习一侧 | 明确初始排序，不画虚构数值 |
| 但这份清晰，并不稳定 | 保留两框和轨道 | 学习的边界由实线变成虚线，重点减弱 | 为后续变化留出上下文 |
| 另一个认知涌现／即时快乐／确定／立刻 | 右侧仍是同一个刷抖音对象 | 信息框从右侧移入，依次呈现即时快乐、确定、立刻，落到右侧框内 | 借鉴样片 02:10～02:18 的“新信息进入既有关系图” |
| 学习的回报是遥远的、模糊的 | 左侧学习框仍在，右侧信息仍在 | 学习框收缩、边界变暗变虚；标签保留可读；右侧框扩大 | 借鉴样片 00:34～00:49 的相对尺寸收缩 |
| 价值排序，瞬间被覆盖 | 对象位置不变 | 比较符号翻转为 <，强调边框由学习侧转到刷抖音侧 | 让排序变化可见，不清屏换图 |
| 重新认知到刷抖音更划算 | 原行动点与轨道 | 同一个行动点沿轨道移向刷抖音 | 动作跟随当前排序，避免点消失后另起一个 |
| 又拿起了手机 | 保留最终排序和行动点 | 行动点在右侧停住，旁边出现简洁手机轮廓 | 用原句收尾，不增加额外结论或片尾 |

字幕沿用整句约 0.2 秒渐显、统一暖白，不采用参考样片的逐字明暗变化。BGM 使用已有 default.mp3，音量沿用项目设置。画面主体止于 y=850，字幕保持独立底部区域。
