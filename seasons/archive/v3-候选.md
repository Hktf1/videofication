```bash

```

## 处理稿标记

在标记列写 `类型:参数1/参数2`（参数用 `/` 分隔，不能有空格）：

| 标记 | 示例 | 说明 |
|---|---|---|
| 大字 | `大字:庞氏骗局` | 巨型金色概念字 + 描边剪影；字号按字数自动收 |
| 人群 | `人群:视线` | 剪影人群 + 中心人物 + 虚线标注 |
| 纸卡 | `纸卡:一条路/逻辑正确/没有反馈/形同虚设` | 第一条是卡名，其余是朱红勾选项 |
| 选项 | `选项:对的方向/感觉对的方向/2` | 两个描边胶囊；第三个参数写 1/2 指定高亮哪一侧，默认 1 |
| 计时 | `计时:希望/3.0/下` | HUD + 大数字；第三个参数写「下」= 倒计时，最后 1/3 变红 |
| 节点 | `节点:你/焦虑/内耗/怀疑` | 一圈节点轮流亮起；第一个是中心，其后是标签 |
| 警报 | `警报:放弃` | 红环 + 心跳线 + 边缘红光 |
| 标题 | `标题:半途而废/为什么` | 金字大标题 + 细线 + 眉题 |

关键词仍用 `【】`，暗调样片里映射为朱红（`emColor`）。
