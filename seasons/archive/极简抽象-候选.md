# 极简抽象（候选，2026-10-24）

以阅读体验为主、视觉解释为辅：普通语句只有居中字幕，关键语义才出现抽象线条与节点。当前样片是 03-3《反馈接管了你的行动》的「正反馈 vs 负反馈」两段。

## 视觉规范

- 画幅 16:9（1920×1080），纯黑 `#000000`。
- 字幕楷体（`engine/public/fonts/simkai.ttf`），88 号，白色 `#F1F0EB`；`【】`关键词暖金 `#E4BC75`。
- 居中单行，最多一行；行尾标点自动隐藏，行内 `，。；` 显示为空隙。
- 普通屏约 0.4 秒渐显、0.4 秒渐隐；一秒以内的短屏按屏长自动缩短淡化，保证有足够时间看清。
- 核心句可逐字渐显（`金句`）并做 0.985→1 的轻微缩放。
- 不放章名、署名、进度条、装饰性光效或粒子。

## 画面语言（点与路径）

- 一条极细的主干从左画出；关键语义处分叉成上下两条路。
- 正反馈：上方支线收到反馈弧，转金色，节点依次亮起，反馈环闭合。
- 负反馈：下方支线的反馈弧只画一半就断掉，保持灰色。
- 停滞：路径在到达终点前被截断，反馈弧与环一起暗下。
- 断裂：整条路径出现虚线断口并变暗。
- 画面连续：整片只有一个 SVG，状态只在每个标记后的 0.6 秒内过渡，其余时间保持；不硬切、不逐屏重置。
- 只有标记屏才出现抽象动画；普通屏只有字幕。每屏最多一个抽象标记。

## 处理稿标记

`抽象:类型/阶段` 写在标记列，与文字、`停留`、`金句` 用空格分隔。

| 标记 | 画面动作 |
|---|---|
| `抽象:路径/起点` | 画出左侧主干与起点节点 |
| `抽象:路径/延伸` | 上方支线继续向终点延伸 |
| `抽象:路径/停滞` | 路径在终点前截断，反馈弧与环暗下 |
| `抽象:路径/断裂` | 全路径出现虚线断口并变暗 |
| `抽象:分叉/展开` | 上下两条支线展开 |
| `抽象:分叉/转下` | 注意力转向下方支线，上方变暗 |
| `抽象:反馈/接入` | 上方反馈弧接入主干并转金色 |
| `抽象:反馈/缺失` | 下方反馈弧只画一半就断掉 |
| `抽象:循环/闭合` | 上方支线的反馈环闭合 |
| `抽象:节点/上行` | 上方支线亮起下一个节点（最多 3 个） |
| `抽象:节点/下行` | 下方支线亮起下一个节点（最多 3 个） |

## 与 v2 的差异

- v2 只有字幕；极简抽象在关键语义屏加入连续的路径动画。
- 字幕渐显/渐隐由 0.2 秒 / 直接消失改为 0.4 秒 / 0.4 秒交叉淡化。
- `【】` 由与正文同色改为暖金色。
- 新增 `抽象:` 标记；`风格：极简` 目前是实验候选，`tools/preflight.ts` 已放行并校验至少一个抽象标记。
