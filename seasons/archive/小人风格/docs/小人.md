# 小人风格

正式风格，程序标识为 `小人`。制作前先读 [风格入口](README.md)。下文代码路径均相对于项目根目录。

运行 `npm run studio`，打开「小人模板」→ `figure-template` 查看八种动作。正式篇目、分节预览、联络表和导出共用同一个 Episode 组件及时间线。

新章节的风格由用户在开工前选定；用户选择小人时按本文制作。02-2 已设置为小人风格；各章实际制作进度以章节 status.md 为准。02-1 未改动，仍按 v2 输出。旧稿未写风格时默认 v2，以免旧视频被自动换风格。

在 script.md 头部设置：

```markdown
---
标题：到底什么时候该放弃
风格：小人
---
## 02-2 到底什么时候该放弃
先看清眼前的选择 | 小人:选择/方向
不要急着下结论
遇到阻碍，再停下来想想 | 小人:受阻/障碍 停留
```

动作支持：站立、前进、犹豫、受阻、重负、放弃、选择、希望。标签可省略，最多 8 字，不含空格或 `/`。如 `小人:犹豫`、`小人:希望/正向反馈`。

后续字幕未写动作时沿用前一个分镜。相邻相同动作和标签连续播放，不会每换字幕都重新进场；动作或标签变化会开始新语义分镜，人物保持在同一画布上，由上一段末态平滑过渡到下一段。首屏未标记时站立。单独导出分节时会继承该分节前最近指定的动作；动画从分节起点重新播放。

纸底、墨线人物、朱砂强调色和底部字幕复用墨线实验的视觉组件；这些是通用动作，不是把 02-1 的专属动画原样套用。复杂隐喻和连续故事需要额外设计。转折空屏期间人物与道具保持上一段末态，下一语义单元开始时继续变换，末尾柔和退场后留白。

制作流程仍为朗读稿审核 → 配音 → 字幕对齐 → 编写分镜标记 → `npm run check -- 02-2 --ready` → Studio 审核 → 导出。小人稿没有任何动作标记时会阻止正式导出。改回旧风格可写 `风格：v2`。

## 视觉规范与实现

- 画幅：1920 × 1080，16:9。
- 暖纸底色 `#EDE3D0`，有 `engine/public/ink/paper.jpg` 时叠加纸纹。
- 墨线与正文色 `#241F19`，朱砂强调色 `#B4432D`。
- 字幕沿用楷体，默认 80 号，纵向位置 y=900；每屏按语义切分，推荐 10～18 字。
- 人物动作表达当前句意；相同场景可跨多屏字幕，不必每句更换动作。
- 色板与布局：`engine/src/style/ink.ts`；人物：`engine/src/kit/FigureScene.tsx`；正式组合：`engine/src/Episode.tsx`；动作继承：`engine/src/script/figure.ts`。

## 连续转场

每个语义单元结束后，主要元素自然变换到下一画面，不直接替换整幅场景。人物位置、弯腰、屈膝、步态强度连续插值；道路与障碍使用相同路径拓扑弯折变形；目标点移动，墨团随姿态移动并收拢或铺开，标签轻移淡交接。默认0.9秒缓入缓出，短分镜自动缩短；不增减字幕、配音或整片时长。实现见 engine/src/script/figure-motion.ts。
