# 纯文字风格

正式风格，程序标识为 `v1`（2026-10-28 由 `v2` 改名，画面没有任何变化）。在章节 `script.md` 头部显式填写 `风格：v1`。制作前先读 [风格入口](README.md)。

极简：纯色底 + 单行居中文字 + 少量有意义的动效，配真人朗读、BGM、少量音效。
实现参数见 `engine/src/style/theme.ts`、`engine/src/style/sfx.ts`、`engine/src/script/timing.ts`，字幕动效见 `engine/src/kit/Subtitle.tsx`。下文代码路径均相对于项目根目录。

- 背景 #000000（纯黑），文字 #F1F0EB，强调 #E4BC75（唯一强调色）
- 楷体（engine/public/fonts/simkai.ttf，系统楷体兜底），字重 400，字号 88，字距 0.04em（用户 2026-10-17 看样片后选定）
- 画面视觉中心固定一行（y=515，比几何中心略高），10～18 字按语义断；行尾标点一律不显示，句中标点照常显示（不再用空白代替）
- 普通：0.2s 原地淡入（不位移），结束直接消失；【】与正文同色
- 主旨：逐字显现 + 字距收拢，念完 0.8s 内转强调色（唯一会变色的情况）；金句：逐字由虚到实
- 转折（行尾 >）：前句消失 → 空屏 0.45s → 后句 0.4s 由虚到实浮现；停留：念完多停 0.7s
- 片头不留黑屏：第一帧就是第一屏，人声从 0 秒开始，背景音乐 0.6 秒淡入；BGM 整片铺底，音量 0.14（见 `docs/背景音乐.md`）
- 水印（可选，默认不加）：处理稿头部写 `水印：是` 时，右下角常驻「公众号：示例账号」，楷体 38 号、灰 #7C8089、距右 40px、距底 30px，片头 0.4 秒淡入
- 片尾（可选，默认不加）：头部写 `片尾：是` 时，结尾加 3 秒片尾卡，黑底居中「公众号：示例账号」（76 号）+「关注不迷路」（38 号灰字），只淡入不淡出，片尾时右下角水印隐藏
- 时长按 4 字/秒 + 标点停顿估算；有配音后全部取自逐字时间戳，停留、转折在配音后补静音
- 去掉：小圆人、Hud、Callout、Card、震动、转折卡、多色调
- 改风格样片：`npm run sheet -- 样片` → seasons/out/

## 修订记录

- 2026-10-17（2026-10-19 补记）：字体字号从思源黑体 Medium 76 号改为楷体 88 号；淡入改为原地渐显（`LAYOUT.rise = 0`），且只渐显不渐隐（`Subtitle.tsx` 默认 `fadeOut = 0`）；【】不再单独变色，只有主旨句整句转强调色；有配音后不再靠标记列写秒数，时刻全部跟逐字时间戳。色板、断句规则、转折与停留节奏不变。
- 2026-10-24：按用户要求，背景由 `#191C22` 改为纯黑 `#000000`；文字与强调色不变。旧章节重新渲染同样变为纯黑。
- 2026-10-24：加入背景音乐与 1 秒片头静场。此前 `engine/public/bgm/` 为空，成片全程没有 BGM，屏间留白是绝对静音；现在缺 BGM 会直接拦截导出。详见 `docs/背景音乐.md`。
- 2026-10-24：句中标点恢复显示——此前逗号、句号会被替换成 0.6em 的空白，句子中间看起来像断了一截；现在直接显示标点。行尾标点一律不显示（含问号）。同时引入节奏谱（见 `docs/节奏谱.md`）。
- 2026-10-26：按用户要求加入右下角公众号水印与 3 秒片尾卡（`engine/src/kit/Watermark.tsx`、`engine/src/kit/Outro.tsx`），旧规则里「去掉角标」不再适用。片尾卡是唯一允许超过 1.8 秒没有人声的段落；合并全片时只保留最后一章的片尾。
- 2026-10-27：按用户要求改为**按需添加**：默认不加右下角水印和片尾卡，只有处理稿头部写 `水印：是` / `片尾：是` 时才渲染（`brandOf` 读取开关，`outroFrames` 决定时间线是否加片尾）。此前渲出的成片带署名，重渲才会变干净。
- 2026-10-27：按用户要求去掉片头 1 秒黑屏（`INTRO_FRAMES` 30 → 0）：第一帧就是第一屏、人声从 0 秒开始，只剩字幕本身的 0.2 秒淡入和 BGM 的 0.6 秒淡入。
- 2026-10-27：`片尾：是` 改为只写在最后一章（前面各章只写 `水印：是`），免得合并时逐章裁剪片尾触发全片重编码。同时也调快了渲染：`tools/render.ts` 传 `--concurrency=12`（Remotion 默认只给一半核数、封顶 8）和 `--x264-preset=veryfast`。
- 2026-10-28：按用户要求，程序标识由 `v2` 改为 `v1`，成为唯一的正式风格；同日机制图形（`v3`）整体删除并归档到 `seasons/archive/机制图形/`。画面参数不变，已有稿件的 `风格：v2` 已全部改写为 `风格：v1`。
