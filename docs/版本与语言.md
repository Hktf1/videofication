# 版本与语言

一篇文章 = 一份原文 + 若干制作版本。版本是一种语言、一套风格与完整脚本（章节、配音、字幕、成片）。唯一正式风格是 V1 极简动效，原 V4 已重命名。

## 命名与选择

| 层 | 命名 | 示例 |
|---|---|---|
| 文章 | NN-短名，不带风格；中文部分最多 4 字 | 17-奖励陷阱 |
| 版本 | 语言-风格标记，可追加用途 | 中文-极简动效v1、英文-极简动效v1 |
| 章节 | NN-M-章名，各版本可同名 | 16-1-章名 |

版本目录靠版本.md 识别，里面记录语言、风格和音色。新建默认中文-极简动效v1；未写语言前缀自动补中文。自动导入的新输入版本名带用户脚本/原文及输入摘要，防止覆盖已有制作稿。
从待制作选取 docx 建文件夹时，按主题概括短名，不机械截断标题；原始 docx 文件名和正文不改。new 命令在创建目录、搬入 docx 前校验中文字符总数，超过 4 字会拒绝。数字、英文和标点不计入中文字符数，既有长目录名不追溯修改。

文章目录按「待制作 → 制作中 → 待发 → 已发」流转：待制作放未开工素材，新建及 auto 开工后进入 `episodes/制作中/`，合并成功后进入待发，发布后进入已发。`--dry` 不搬目录。移动按整篇进行，原文、版本、声音、字幕和成片一起移动，编号不变。

status.md 的当前版本决定默认操作；只有一版直接选，多版且未指定时取最近修改的一版。--version 或 NN-M@版本 显式选择，缺章不回退到另一版。v1 简称优先匹配当前动效版本，多候选时必须写全名；历史 v4 简称兼容动效 V1。status/progress 展示全部素材，正式 Studio 隐藏停用纯文字稿。

```bash
npm run new -- "标题"
npm run version -- NN "极简动效v1"
npm run version -- NN
npm run auto -- NN --version 中文-极简动效v1
npm run auto -- NN --script "D:/稿件/口播.txt"
npm run version -- NN "极简动效v1" --from "中文-纯文字v1"
```

## 语言与配音

版本.md 可填语言：英文、语言代码：en-US、音色：en-US-GuyNeural。中文默认 zh-CN/云健，英文默认 en-US/Guy，其他语言必须写语言代码和音色。演出稿 @音色 可覆盖版本默认值，@默认 只重置语速等参数。识别使用同一语言，英文字幕保留词间空格、对稿忽略大小写。

配音或识别配置变化后重新处理。旧声音复用时比较朗读稿、演出稿、配音摘要与实际声音配置，不因风格重命名就重配，也不因复制时间改变而误判。

## 成片与历史素材

章节成片在章节 out，整片在文章 out/NN-标题-版本.mp4；composition id 含版本以区分同名章节。新成片 manifest 写 style: v1、styleId: motion、version 和 language。历史 manifest 原样保留：无稳定标识的 v1/v2 是纯文字，v4 是动效；未知风格视频不能当作新动效结果复用，也不直接覆盖。

纯文字版本保留旧目录名用于定位素材，版本.md 和 script.md 标 legacy-text，不能作为正式风格创建或直接渲染。重做时用 --from 复制可复用文字与声音到独立 V1 动效版本；已有成片不复制。见 [旧文章重做](旧文章重做.md)。极简2D叙事是独立定制版本，保留专用入口。

第 6 篇部分纯文字章节只剩历史成片，恢复这些章节台词前不能复制成不完整的新版本。第 15 篇中英文极简2D叙事继续保留，其普通动效目录已更名为极简动效v1。
