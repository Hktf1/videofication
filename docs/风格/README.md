# 视频风格统一入口

唯一正式风格是 **V1 极简动效**（原 V4）。新稿填 `风格：v1`，默认版本为 `中文-极简动效v1`，英文为 `英文-极简动效v1`。

**极简指视觉统一、信息克制、容易理解。** 深蓝黑底、统一字体与语义色、底部整句暖白渐显字幕；中央可用物体、简化人物、手势、界面、场景、图解和动态文字。先按内容选表达，母题可选，不优先套抽象图元；允许连续多屏保持，必要动作按真实声音同步，场景内保持对象与布局稳定。具体标准见[正式规范](极简动效.md)。

先写分镜并自检，再实现、检查并打开预览，用户看预览后确认本章。仅用户本次明确要求先审分镜时才停在分镜阶段；全自动不增加逐章确认。技术检查、布局、动态和理解检查分别记录，见[画面验收与版本记录](../开发与导出检查.md#画面验收与版本记录)。

先读根目录 CLAUDE.md，再读本入口与正式规范。用户提供脚本时先读脚本，只补缺少的制作层；无脚本时才从原文准备。见[全自动流程](../全自动流程.md)、[版本与语言](../版本与语言.md)。

纯文字风格已停用，正式引擎已删除其独立展示分支；V1 仍可按正式规范使用短句和动态文字。旧稿标 `legacy-text`，保留原文、稿件、声音、字幕和成片，不能只改风格标记就算重做，见[旧文章重做](../旧文章重做.md)。

旧 v4 输入兼容读为动效 V1。历史 manifest 不带 styleId 的 v1/v2 是纯文字，v4 是动效；新成片写 `style: v1`、`styleId: motion`。seasons/archive 为历史资料，不自动恢复为制作选项；既有定制极简 2D 版本继续独立保留。

水印与片尾默认不加，明确要求时才开启，片尾仅放最后一章。规范调整与代码、视频实现分开记录；组件扩展和验收方法以实际实现为准，不能把文档更新当作画面完成。
