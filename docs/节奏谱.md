# 节奏谱

## 是什么

节奏谱是**在写分镜之前，先决定整章的时长分布和呼吸点**。

它不管「字幕和配音是否对齐」——那是对稿和逐字时间戳的事，精确到帧。节奏谱管的是更大的一层：90 秒里，哪里快、哪里停、哪里留白。相当于给整章排一张谱，再往里填句子。

不管节奏谱，每一屏的长度就会等于它那句话的长度，节奏成了断句的副产品：短句一闪而过，长句拖在那里，重点和废话一样长。管了节奏谱，长短是由意思决定的。

## 三个杠杆

`script.md` 里只有三样东西能改变时序：

| 写法 | 作用 |
|------|------|
| 合并 / 拆分屏 | 决定文字多久换一次。合并＝停留更久，拆分＝变化更快 |
| `| 停留`、`| 停留1.0` | 念完后字继续留在屏上（默认 0.7s） |
| 行尾 `>` | 字消失后留一段空屏（0.45s），用来做段落之间的呼吸 |
| `| 3.5s` | 强制这一屏的总时长，多出来的时间是静默 |

## 规则

- **单屏不短于 1.6 秒**。再短就来不及读完，只会看到闪一下。例外是刻意的加速串（见下条）。
- **加速串**：2～3 屏连续的短句（1.6～2.2s），用来制造紧迫感。列举、递进、排比适合这样处理。
- **落点**：每隔 25～35 秒安排一个 4～6 秒的长屏，把前面的加速收住。
- **锚点**：每章 3～4 个，是全章最重要的句子。锚点的写法是「关键句 + `停留` + `>`」，让声音停下、字消失、空一拍。
- **锚点前面要有加速**。没有加速，锚点就不像锚点。
- **开头两屏要留住人**：第一屏短、第二屏稍长，不要一上来就是长句。
- **结尾放慢**：最后两屏可以用 `停留` / `停留1.0`，让收束落下来。注意成片有 1.8 秒的空白上限（见下），章尾的停留会占用与下一章之间的间隔（2026-10-27 起片头不再有 1 秒黑屏，这个间隔只剩配音尾巴），实际保留可能很短。
- `停留` 不要超过全章屏数的 20%（`npm run check` 会提示），否则处处都是重音，等于没有重音。
- **成片最长空白 1.8 秒**：有配音时，任何一段没人声的时间（含章与章拼接）都不超过 1.8 秒。`停留` 和 `>` 的空白超出会被自动压短（`engine/src/script/timeline.ts` 的 `MAX_VOICE_GAP`），所以节奏谱里写的停留是上限，不是保证值。

## 自查

```bash
npm run pace -- 03-2     # 单章
npm run pace -- 03       # 整篇
```

先打印每屏的实际时长、条形图和统计（平均值、标准差、最短/最长、过短屏数）。低于 1.6 秒的屏会标 `←`，逐条确认是刻意的加速还是断句碎掉了。

然后打印**声音节奏**，这一层屏长看不到：

```
— 声音节奏 —
  语音块 29 个，平均 1.9s，最长 3.8s
  语速 4.0～6.0 字/秒（均值 5.1，起伏 38%）
  停顿 28 处：换气(<0.5s) 16、分句(0.5～0.75s) 4、段落(0.75～0.9s) 5、转折(>0.9s) 3
```

- **语音块**：静音用 ffmpeg 从配音里直接测（ASR 的字时间戳会把静音并进词尾，按字间隔算会把句号停顿整个丢掉），两块语音之间就是一处停顿。连续 ≥8 秒没停顿会标「平坦区」，那段听众会走神。
- **语速起伏低于 20%** 说明全章一个调，看演出稿是不是所有句子都用了同一个预设。
- **停顿分层**按 0.5 / 0.75 / 0.9 秒切四档，对应演出稿的换气、分句、段落、转折。某一档是 0，说明这一类停顿在这章根本没出现，节奏只有一个层级。

屏长决定「字什么时候换」，声音决定「耳朵听到什么」。两边都要看：屏长整齐但语速起伏只有 15% 的章节，看起来规整，听起来是一条直线。

## 示例：03-坚持

| 章 | 屏数 | 时长 | 平均 | 最短 | 最长 |
|----|------|------|------|------|------|
| 03-1 | 25 | 76.3s | 2.95s | 1.6s | 3.9s |
| 03-2 | 31 | 95.1s | 2.99s | 1.7s | 5.8s |
| 03-3 | 43 | 127.0s | 2.90s | 1.4s | 4.9s |
| 03-4 | 25 | 77.1s | 2.98s | 2.1s | 4.4s |

03-3 最短的 1.4s 出现在「别人成功的案例／书本上的道理／鸡汤文里的金句」这一组——刻意的加速串。

（2026-10-24 修掉分段静音放大后重配，四章比之前分别短了约 7、10、18、14 秒，平均屏长从 3.25～3.56s 收到 2.90～2.99s。）
