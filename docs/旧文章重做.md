# 旧纯文字文章重做

不用先删除任何文章素材。纯文字风格的正式展示分支已删除，旧文章进入独立的极简动效 V1 版本重做。

| 内容 | 如何处理 |
|---|---|
| 原始 docx、source.txt、分章原文 | 保留，作为内容来源 |
| 朗读稿、演出稿 | 台词不变时复用，换台词后同步 |
| 配音、逐字.json、识别配置 | 台词、演出、语言和音色一致时复用 |
| 校正.srt | 可作参考，重新切屏后由 voice 按新稿生成 |
| script.md 台词、强调、切屏 | 保留可用部分，补新画面设计 |
| 旧居中文字排版、文字专属展示动效 | 不再用于新片，由动效画面替代 |
| 旧纯文字 MP4 和 manifest | 已临时归档到 backup/临时-纯文字视频-20261028，清单记录原路径与摘要，不作为新版本结果 |
| 缓存与临时文件 | 按需清理，与换风格无关 |

```bash
npm run version -- NN "极简动效v1" --from "中文-纯文字v1"
```

只向空的新版本复制台词稿、演出稿、完整配音和字幕，不覆盖旧版，不复制旧视频。新版本先使用基础动效，Agent 可进一步按台词做定制图解。配音复用记录含输入摘要，改台词、演出、音色或语言后重新配音；改字幕切屏通常只需重新对齐、生成字幕和渲染。

来源有“历史成片”章节（只有视频没有台词源稿）时会停止，避免只复制其余章节制作不完整全片。先恢复缺失章节的台词，再重做；第 6 篇目前有这种情况，完整旧片已保留。

新版本已有章节时不覆盖，可改用 `极简动效v1重做2`。用户同时提供新脚本时，直接 `npm run auto -- NN --script "路径"`，新脚本优先于旧纯文字稿与原文。
