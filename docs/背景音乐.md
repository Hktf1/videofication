# 背景音乐与音效

V1 极简动效以配音推动字幕和图解。没有 BGM 时，语句之间的正常留白会变成绝对静音，影响声音连贯性。因此背景音乐必需，check 和导出检查都会拦截缺失的 BGM。

## 文件

```
engine/public/bgm/default.mp3     默认 BGM：time is broken（用户指定，已标准化到 -23 LUFS）
engine/public/bgm/room-tone.mp3   备选：合成底噪（npm run bgm 生成）
engine/public/bgm/<名称>.mp3      备选，script.md 里写 BGM：<名称>.mp3
engine/public/sfx/hit.mp3         重点
engine/public/sfx/glow.mp3        亮起 / 出路
engine/public/sfx/iron.mp3        铁律
engine/public/sfx/weight.mp3      额外消耗 / 负反馈重量
engine/public/sfx/supply.mp3      正反馈补给
engine/public/sfx/gavel.mp3       法槌
engine/public/sfx/collapse.mp3    路板散落
engine/public/sfx/来源.md         来源、许可与处理记录
```

- 章节 `script.md` 头部不写 `BGM` 时用 `default.mp3`，写了就用对应的文件
- `default.mp3` 来自 `D:\视频草稿\time is broken.MP3`（2026-10-27 起作为默认 BGM）：原文件只有 -36 LUFS、峰值 -27 dBFS，太轻，已整体 +13 dB 标准化到 -23 LUFS，并裁掉末尾 33 秒静音（有效长度 188 秒）、末段 0.8 秒淡出。要换回合成底噪，把 `BGM：room-tone.mp3` 写进处理稿即可
- 音效只在处理稿标记了音效名的屏才需要文件；标记了却没有文件，`check` 报错
- 文件缺失时引擎会静默跳过（`Episode.tsx` 的 `has()`），所以一定要靠 `check` 把关

## 音效延迟与来源

- `script.md` 标记写 `音效：法槌@2.3`；`@` 后是相对本屏开头的秒数，省略为 0。音效在屏与屏之间连续播放，不会被下一屏截断。
- 一屏写多个音效时共用一个延迟值；需要不同落点时拆屏，或把音效标到动作所在的那一屏。
- 新增音效：文件放 `engine/public/sfx/`，在 `engine/src/style/sfx.ts` 加语义名和中文别名，并在 `来源.md` 记录 URL、作者、许可与处理。只用 CC0 / 公有领域或明确允许商用的库；不确定的站点不要用。
- 处理：裁掉首尾静音，峰值约 -6～-8 dBFS，转 192k MP3；混音音量由 `VOLUME.sfx` 统一定义，单条不要单独加增益。

## 生成合成底噪

```bash
npm run bgm               # 生成 engine/public/bgm/room-tone.mp3（90 秒）
npm run bgm -- calm 120   # 生成 calm.mp3，120 秒
```

`tools/make-bgm.ts` 用纯正弦叠加合成，所有分音频率和起伏周期都是 1/时长 的整数倍，循环点严格无缝。没有人声、没有旋律钩子，只提供「房间里还有东西在响」的底噪。

注意：默认输出已改为 `room-tone.mp3`，不会覆盖 `default.mp3`（用户指定的曲子）。

## 换成自己的音乐

直接把文件放进 `engine/public/bgm/`，在 `script.md` 里写 `BGM：文件名.mp3` 即可，不需要改代码。默认曲子（`default.mp3`）是用户选的有旋律的曲子，说明「配乐」也能用；下面的建议只在还想做纯底噪时参考：

- 不要有人声，会和配音抢注意力
- 旋律越强，越要把音量再压低一档（见下节），让人声保持主位
- 循环接缝要干净；长度最好覆盖单章时长（当前各章 70～130 秒），避免中途回环。`default.mp3` 有效长度 188 秒，覆盖所有单章

## 音量与片头

在 `engine/src/style/sfx.ts` 统一定义：

- `VOLUME.bgm = 0.18`：`default.mp3` 标准化后是 -23 LUFS，乘 0.18 约 -38 LUFS，比配音（约 -24 LUFS）低 14 dB。合成底噪原本是 -19 LUFS / 0.14，混音结果只差 2 dB，换成有旋律的曲子时略压低，保证人声主位
- 换 BGM 文件时先量响度（`ffmpeg -i 文件 -af loudnorm=print_format=json -f null -`），按「混音后比配音低 13～15 dB」反推 `VOLUME.bgm`，不要在代码里加增益
- `BGM_FADE = 0.6` 秒：片头淡入，避免第一帧突兀出声
- `INTRO_FRAMES = 0`（`engine/src/script/timeline.ts`）：2026-10-27 起不留片头静场，第一帧就是第一屏，人声从 0 秒开始；此前是 1 秒黑屏 + BGM
