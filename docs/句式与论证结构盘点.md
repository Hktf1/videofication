# 跨文章句式、表达关系与论证结构盘点（草案）

日期：2026-11-01。样本：项目 5 篇已开工文章的 source.txt，以及待制作目录下 20 份 DOCX，共 25 篇、约 3.6 万字符。DOCX 只读取正文，首行保留；未移动、改写原文。

目的：先找不同文章反复表达的关系，再决定需要哪些画面能力。本文是分析草案，不是制作规则，不改变现有风格、代码或视频。

## 如何使用这份清单

- 分三层：**基本表达关系 → 句间组织方式 → 多句论证模块**。分类可重叠，可组合；不是互斥的语言学全集，也不是 62 个画面模板。
- “同句式”不一定“同关系”：不是 A 而是 B，可能在纠正概念、纠正归因、改变目标、区分来源或倒转因果。应读完整意思及上下文。
- “同关系”也不一定“同句式”：因为、导致、使、于是，以及省略连接词的相邻句，都可能表达因果。词面检索只能找候选，不能代替语义判断。
- 下列例子是对原稿的结构概括，非逐字引文；A/B/C 表示变量。A→B 表示原稿所主张的方向，不表示该因果已得到事实核验。假设、比喻、概率、主观观点与已发生事实应区分。
- 来源编号代表该组关系的样本来源，不表示每个子类在每篇都出现；本轮未做逐句标注，不报告语义覆盖率或频次排名。后续用真实片段校正、合并和拆分分类。

## 第二层：12 类句间组织方式

这一层说明一句话如何接到前文，不决定要新增对象或动作。

| 类型 | 作用 | 常见语言线索 |
|---|---|---|
| 设问 | 提出需要解释或解决的问题 | 为什么、怎么、究竟 |
| 反问 | 用问句加强否定、肯定或质疑 | 难道、不是吗、怎么可能 |
| 自问自答 | 提出问题后立即给出答案 | 原因是什么？答案是…… |
| 承接与指代 | 继续解释前面同一对象或关系 | 这、这种、它、前者、后者 |
| 补充与递进 | 增加一层理由、后果或更重要的问题 | 并且、不仅、更严重、甚至 |
| 转折与纠偏 | 改变上一段建立的判断或预期 | 但是、然而、其实、反而 |
| 让步与限缩 | 承认一部分，再限定其成立范围 | 即使、虽然、但不意味着 |
| 改述与归纳 | 用另一种说法概括已有内容 | 换句话说、也就是说、本质上 |
| 举例与实例化 | 用一个或多个具体实例支持、说明关系 | 例如、比如、再看 |
| 类比与映射 | 借另一场景解释相同或相近的关系 | 就像、好比、类似于 |
| 引述与立场切换 | 区分作者主张、他人观点和内心独白 | 有人认为、你对自己说、我以为 |
| 总结、回扣与强调 | 收束已有论证，或回到开头的命题 | 所以、综上、回答开头、看清楚 |

同一个“反而”可能表达反预期结果，也可能强调程度变化；同一个“这”可能继续解释旧对象。遇到新连接词不等于换场。

## 容易混淆、必须保留的区别

| 容易合并的表达 | 应区分什么 |
|---|---|
| 先后发生 / 因果成立 | A 在 B 前面，不自动证明 A 导致 B |
| 如果 A 则 B / 只有 A 才 B | 充分条件与必要条件方向不同；单看“如果/只有”也不够，需核对作者实际主张 |
| 否定 A / 用 B 替代 A / 保留 A 但改变关系 | 对象删除、概念纠正、关系解除是不同操作 |
| A 不同于 B / A 比 B 更好 | 区分概念不自动含价值排序 |
| 示例 / 比喻 / 假设数据 / 统计证据 | 示例不能擅自变成统计比例；假设数字不能当实测值；比喻不能反过来证明原命题 |
| 多项列举 / 多因素共同作用 | 同类例子可以同位替换，协作因素可能必须同时保留 |
| 正反馈 / 有利结果；负反馈 / 恶性循环 | 原稿“正/负反馈”常指结果好坏；控制系统中的正负反馈另有含义。必须看回路是否强化或抵消变化，不能把负面结果一律画成恶性循环 |
| 即时变化 / 长期变化 | 短期减压可以同时伴随长期恶化，不能只展示某一个时间尺度 |
| 重复 / 迭代 / 循环 | 重复是再发生；迭代含根据反馈修改；循环含回到前面的状态或变量 |
| 事实不存在 / 作者不知道 / 作者认为不存在 | 真实状态、认知状态与立场不同；虚线或暗色不能承担所有区别 |
| 无能 / 暂时不会 / 尚未找到方法 | 稳定属性与可变状态不同，不能用同一个失败符号抹平 |
| 同一对象变化 / 换了一个对象 | 前后比较需要身份连续；同类替换则需要明确何时换项 |

## 三段跨文章重复的实例

### 收藏、改变幻想、成功幻想

A05、A10、A24 题材不同，共同结构是：不满意现状 → 产生不适 → 采取即时缓解行为 → 不适下降 → 原问题未改善 → 再次需要缓解；部分原稿进一步写到剂量提高、效果递减或后果加重。这些附加环节不能默认给每一篇都补上。

### 错误归因、失败信心、研究天赋

A07、A14、A23 都会把宽泛的身份判断展开为可检查的原因：看到失败 → 贴上固定标签 → 停止进一步观察或尝试；再回到具体方法、条件、数据与修正。可共享“标签与可变原因”的关系设计，不需要共享数学、骑车、分手等具体道具。

### 理解幻觉、学习动力、努力质量

A01、A21、A12 都区分一种主观判断与它是否真的成立：读得顺不等于独立会用；抽象知道重要不等于理解具体收益；感到痛苦不等于有效推进。共同设计问题是比较标准和证据来源，不是“看到否定词就打叉”。

## 后续怎样用来建立画面能力

下一步应先从不同文章各选真实片段做标注，而不是立即为 62 个条目各写组件。每个片段记录：主体和客体、关系及方向、条件、比较基准、时间尺度、事实/假设/比喻/立场、篇内作用，以及是否需要画面变化。

优先为跨文章出现的“纠正解释、共同基准比较、机制链、条件边界、预期与实际、资源分配、重复递减、循环与干预、试错迭代、步骤分支”建立多例参考。每种至少看不同内容的实例，检查关系能否复用、对象是否仍然直观；没有必要变化的句子允许保持。

空间运动、人物表情、场景取景和图表样式属于后续表现层，不与句式一一绑定。现有六段视频只是部分实例，不能决定这份分类的范围。科普、故事、人物采访等新题材加入后，还需扩展空间、人物意图与叙事视角等关系。
